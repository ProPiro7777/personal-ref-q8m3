# 호이4(HOI4) 모드 분석 프로젝트 — 자료 안내

> **이 문서는 프로젝트에 업로드된 모드 파일들이 무엇인지, 어떻게 해석해야 하는지를 AI에게 알려주기 위한 가이드입니다. 다른 모든 파일보다 먼저 참고하세요.**

---

## 1. 프로젝트 목적

사용자는 **Hearts of Iron IV(HOI4) 모드를 직접 제작 중**이며, 기존에 공개된 다른 모드들의 구조·문법·작성 방식을 **양식(레퍼런스)** 으로 삼고 싶어 합니다. AI는 모드 코드의 패턴을 분석하고, 사용자의 모드 제작 질문에 구체적인 예시를 들어 답변하는 역할을 합니다.

업로드된 파일은 **원본 ZIP 파일을 평탄화(flatten)** 한 텍스트 파일들입니다. ZIP은 Claude 프로젝트에 직접 업로드가 불가능하기 때문에, 폴더 구조를 파일 이름 안에 인코딩하는 방식으로 변환했습니다.

---

## 2. 파일명 명명 규칙 (★ 가장 중요)

모든 파일은 다음 규칙에 따라 이름이 지어져 있습니다.

```
[모드 이름]_[원본 폴더 경로를 _ 로 연결]_[원본 파일명].[원본 확장자].txt
```

### 예시 디코딩

| 업로드된 파일명 | 원본 위치 |
|---|---|
| `East Showdown_events_ai.txt` | `East Showdown/events/ai.txt` |
| `East Showdown_common_national_focus_japan.txt` | `East Showdown/common/national_focus/japan.txt` |
| `Equestria at War_localisation_english_main_l_english.yml.txt` | `Equestria at War/localisation/english/main_l_english.yml` |
| `Korea - The Heavens Soldiers [Official Version]_history_countries_KOR - Korea.txt` | `Korea - The Heavens Soldiers [Official Version]/history/countries/KOR - Korea.txt` |
| `Millennium Dawn A Modern Day Mod_common_ideas_USA.txt` | `Millennium Dawn A Modern Day Mod/common/ideas/USA.txt` |

### 해석 시 주의사항
- **파일명 앞부분의 모드 이름은 ZIP 파일의 원본 이름 그대로**이며, 정확한 모드 명칭입니다.
- 끝에 `.txt`가 붙어 있어도, 그 직전 확장자(`.yml`, `.gfx`, `.gui`, `.mod`, `.lua` 등)가 **진짜 파일 타입**입니다. 업로드 호환성을 위해 `.txt`를 덧붙인 것뿐입니다.
- 모드 이름 자체에 공백(` `)이나 특수문자(`[`, `]`, `-`)가 포함될 수 있으니, 모드 경계를 판단할 때는 알려진 모드 목록(아래 §3)을 참조하세요.

---

## 3. 포함된 모드 목록

업로드된 ZIP 파일들의 정체와 특성입니다. 파일을 읽기 전 어떤 모드 소속인지 먼저 식별하세요.

### 3-1. East Showdown
- **분류**: 대체역사 / 시나리오 토탈 컨버전 (부분)
- **내용**: **러시아–우크라이나 전쟁(2022~)** 시뮬레이션 모드. 동유럽 전용 신규 맵, 신규 국가, 신규 기술 트리, 신규 장비/유닛, 3D 모델 등을 추가합니다. 제작진은 중립을 표방.
- **참고 가치**: 현대전 시나리오, 동유럽 지역 신규 맵 추가 방식, 좁은 지역 신규 국가 추가, 현대 장비 정의 양식.

### 3-2. Equestria at War (EaW)
- **분류**: 토탈 컨버전 (대규모)
- **내용**: 애니메이션 *My Little Pony: Friendship is Magic* 의 세계관 "에쿠스트리아"를 배경으로 한 매우 거대한 모드. 종족(포니/그리폰/창조/체인지링 등) 시스템, 마법, 광범위한 포커스 트리, 수십 개의 신규 국가/이념을 보유. **HOI4 모드계에서 가장 콘텐츠가 방대한 모드 중 하나**.
- **참고 가치**: 대규모 포커스 트리 작성, 커스텀 이념 시스템, 복잡한 이벤트 체인, 다중 분기 스크립트, 광범위한 현지화(.yml) 양식의 모범 사례.

### 3-3. Korea - The Heavens Soldiers [Official Version] (천군)
- **분류**: 대체역사 (한국 국뽕 판타지)
- **내용**: 영화 *천군*(2005)에서 영감받은 모드. **근미래(2020년대) 한국군이 1936년 2차 세계대전 시점으로 시간여행**하여 제주도에서 시작하는 시나리오. 원작자는 BlueCokeWine, [Official Version]은 UKKRHEE가 1.13.x로 이식한 버전.
- **참고 가치**: 한국어 현지화(.yml) 양식, 한국 관련 캐릭터/이벤트 정의, 1936 타임라인에 현대 장비/기술 추가하는 패턴.

### 3-4. Millennium Dawn: A Modern Day Mod
- **분류**: 토탈 컨버전 (현대전)
- **내용**: **2000년 1월 1일부터 시작**하는 현대전 토탈 컨버전 모드. 거의 전 세계 모든 국가가 플레이 가능하며, 현대 정치 체제·현대 장비·현대 외교 시스템을 도입. HOI4 현대전 모드의 **사실상 표준**.
- **참고 가치**: 현대 기술 트리, 현대 정치/이념 시스템, 대량의 국가별 데이터 정의 방식. ⚠️ 원본 ZIP이 3.2GB로 매우 크기 때문에, 평탄화된 파일이 매우 많을 수 있습니다.

### 3-5. Naval Invasion Hotkey
- **분류**: 유틸리티 / QoL (Quality of Life)
- **내용**: **해상 침공(naval invasion) 명령에 단축키를 추가**하는 작은 유틸 모드. 게임 메커니즘은 거의 건드리지 않고, 인터페이스(GUI)와 입력 처리만 손봅니다.
- **참고 가치**: **최소 규모 모드의 구조 예시**. `descriptor.mod`만 보고 모드 골격을 파악하기에 좋음. GUI/단축키 수정 방식 학습용.

### 3-6. supply hub 2000 cost (updated)
- **분류**: 미니 밸런스 모드
- **내용**: 보급 허브(supply hub) 건설 비용을 2000으로 조정하는 단일 수치 변경 모드.
- **참고 가치**: **단일 게임 상수 변경이 어느 파일에서 이뤄지는지** 파악하기에 유용. 대개 `common/buildings/` 안의 단일 파일만 수정합니다.

### 3-7. Toolpack without the Errors
- **분류**: 모더용 디버그 도구
- **내용**: 모드 제작자(modder)를 위한 **디버그 결정/이벤트/콘솔 도구** 모음. 원본 Toolpack 모드의 에러를 제거한 버전. 게임 내에서 국가 변경, 자원 즉시 추가, 디버그 정보 확인 등을 가능하게 함.
- **참고 가치**: **사용자 본인이 자기 모드를 테스트할 때 직접 사용 가능**. 또한 디버그용 결정/이벤트 작성 방식을 학습하기에 좋음.

### 3-8. 타오르는 불릿 (TFR — The Fire Rises 추정)
- **분류**: 대체역사 (어두운 근미래)
- **내용**: **미국 패권 붕괴 후의 세계**를 다루는 모드. 미국이 내전에 빠지고(미연방정부 / 미입헌정부 / 미인민해방군 애국전선 / 국가사회주의 운동 / 핵무기 사단 등 다양한 내전 세력), 동시에 러시아·중국·프랑스·독일·일본 등이 각자의 야망을 펼치는 시나리오. 모든 세력이 자신을 정의롭다고 믿는 시각을 반영. 높은 난이도가 특징.
- **참고 가치**: 내전(civil war) 메커니즘 구현, 다중 분파 정치 시스템, 어두운 톤의 이벤트 텍스트 작성법.
- ⚠️ ZIP 파일명이 "타오르는 불**릿**"인데, 실제 모드명은 **타오르는 불길** 또는 **타오르는 불꽃**(The Fire Rises, TFR)일 가능성이 매우 높습니다. 사용자 확인 필요.

### 3-9. 편리한 게임 도구 - 총참모부
- **분류**: 유틸리티 (한국 커뮤니티)
- **내용**: 한국 커뮤니티에서 제작된 게임 편의 유틸 모드. "총참모부"라는 메뉴를 통해 다양한 편의 기능(자원/유닛/이벤트 호출 등)을 제공할 것으로 추정.
- **참고 가치**: 커스텀 GUI 메뉴 추가, 한국어 인터페이스 작성, 디시전(decision)을 통한 유틸 기능 구현 양식.
- ⚠️ 정확한 기능은 모드 내부 `localisation/` 및 `common/decisions/` 파일을 참조하여 확인 필요.

## 4. HOI4 모드 폴더/파일 구조 가이드

업로드된 파일이 어느 폴더에 속해 있었는지에 따라 **역할이 완전히 다릅니다**. 파일명에서 폴더 부분(`_common_ideas_`, `_events_`, `_history_countries_` 등)을 보고 즉시 역할을 식별하세요.

### 4-1. 최상위 핵심 폴더

| 폴더 | 역할 |
|---|---|
| `descriptor.mod` | 모드 메타정보(이름, 버전, 의존성, 태그). **단일 파일**, 모드의 신원증명서. |
| `/common/` | **게임 메커니즘 정의**. 모드 작업의 80%가 여기서 일어남. |
| `/events/` | 팝업 이벤트 정의 (`country_event = { ... }` 형식). |
| `/history/` | **게임 시작 시점의 초기 상태** (국가 설정, 부대 배치, 외교 관계). |
| `/localisation/` | 모든 텍스트의 번역 (`.yml` 형식, 언어별 폴더). |
| `/gfx/` | 이미지/아이콘 리소스(.dds, .tga, .png). |
| `/gui/` | UI 레이아웃 정의(.gui 파일). |
| `/interface/` | GUI 스프라이트(.gfx) 및 인터페이스 정의. |
| `/map/` | 맵 데이터(지방, 지형, 보급로 등). 토탈 컨버전에만 존재. |
| `/portraits/` | 캐릭터/지도자 초상화. |
| `/music/`, `/sound/` | BGM 및 효과음. |

### 4-2. `/common/` 하위 폴더 (가장 자주 등장)

| 하위 폴더 | 무엇이 정의되는가 |
|---|---|
| `national_focus/` | **국가 포커스 트리** (한 국가의 정치/군사 노선 분기). 모드의 핵심 콘텐츠. |
| `ideas/` | 국가 이념, 자문관(advisor), 디자이너, 기업, 국가 정신(national spirit). |
| `decisions/` | 디시전(decision) 정의 (조건부로 발동하는 액션). |
| `decisions/categories/` | 디시전 카테고리 (UI 분류). |
| `scripted_effects/` | 재사용 가능한 효과 스크립트 함수. |
| `scripted_triggers/` | 재사용 가능한 트리거 조건. |
| `scripted_localisation/` | 동적 텍스트 변수 (예: 국가별로 다르게 표시되는 문구). |
| `on_actions/` | 자동 발동 트리거 (예: 전쟁 발발 시, 매월 등). |
| `countries/` | 국가별 색상 및 그래픽 정의. |
| `country_tags/` | 국가 태그(3글자 코드) 정의. |
| `ideologies/` | 이념 정의 (민주주의/공산주의/파시즘 등 또는 신규 이념). |
| `units/` | 유닛(사단) 템플릿 및 통계. |
| `technologies/` | 기술 트리. |
| `buildings/` | 건물 정의 (공장, 보급 허브 등). |
| `state_category/` | 주(state) 카테고리 (대도시/시골 등). |
| `characters/` | 캐릭터(지도자, 장군, 자문관) 정의. NSB DLC 이후 신형식. |
| `opinion_modifiers/` | 외교 관계 수정자. |
| `wargoals/` | 전쟁 명분. |
| `abilities/` | 장군 능력. |
| `ai_strategy/`, `ai_strategy_plans/` | AI 전략 가중치. |
| `peace_conference/` | 평화 회담 옵션. |
| `operations/`, `intelligence_agency/` | 첩보 시스템. |
| `resistance_*/` | 점령지 저항 시스템. |

### 4-3. `/history/` 하위 폴더

| 하위 폴더 | 역할 |
|---|---|
| `countries/` | **각 국가의 시작 상태** (정치/경제/외교/지도자/시작 기술). 파일명은 `XXX - 국가명.txt` 형식. |
| `states/` | 각 주의 초기 인프라/인구/공장/소유주. |
| `units/` | 시작 시점의 부대 배치(OOB, Order of Battle). |

### 4-4. `/localisation/` 하위 폴더

언어별로 폴더가 나뉩니다 (`english/`, `korean/`, `french/` 등).
- 파일 형식: `*.yml` (UTF-8 BOM 필수)
- 첫 줄은 반드시 `l_english:` 또는 `l_korean:` 등 언어 헤더로 시작.
- `/replace/` 하위 폴더의 파일들은 바닐라 텍스트를 **덮어쓰기** 함.

## 5. 분석 시 추천 워크플로우

사용자가 "X 같은 걸 만들고 싶어"라고 물을 때, AI는 다음 순서로 자료를 활용하세요.

1. **모드 선택**: 사용자가 만들고자 하는 것과 가장 비슷한 모드를 §3에서 식별.
   - 예: 한국 관련 → 천군, 편리한 게임 도구  
   - 예: 포커스 트리 → Equestria at War (양적으로 가장 풍부)  
   - 예: 현대전 → Millennium Dawn, East Showdown  
   - 예: 작은 유틸 → Naval Invasion Hotkey, supply hub 2000 cost

2. **폴더 식별**: §4에서 해당 기능이 어느 폴더에 정의되는지 확인.

3. **파일 위치 추정**: `[모드명]_[폴더경로]_*.txt` 패턴으로 파일명을 좁힘.
   - 예: 천군 모드의 한국 포커스 트리 → `Korea - The Heavens Soldiers [Official Version]_common_national_focus_*.txt`

4. **양식 추출**: 해당 파일을 읽고 사용자의 요구에 맞게 구조를 변형하여 제시.

## 6. 알려진 한계점

- **Millennium Dawn**(3.2GB)은 평탄화 후 파일 수가 매우 많을 수 있습니다. 프로젝트 지식 한도를 고려해 일부만 업로드되었을 수 있습니다.
- 바이너리 파일(`.dds`, `.tga`, `.png`, `.ogg`, `.mp3`, `.dll`)은 평탄화 대상에서 제외되었습니다. 그래픽/사운드 리소스의 **실제 이미지**는 볼 수 없고, 이를 참조하는 텍스트 정의(`.gfx`, `.gui`)만 볼 수 있습니다.
- 일부 모드의 ZIP 파일명이 사용자 보유 시점의 명칭이라, 워크샵 공식 명칭과 약간 다를 수 있습니다(예: "타오르는 불릿" vs "타오르는 불길").
